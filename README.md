# MiniMax H3 Director - Long Video Workflows

ComfyUI workflows used in my tutorial for creating longer videos with MiniMax H3 Director.

## Workflows

- BASE — Initial H3 Director generation
- CONTINUATION — Generate additional segments using a 22-frame overlap
- ASSEMBLY — Reassemble saved segments without recalculating MiniMax H3
